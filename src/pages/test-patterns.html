Every pattern the guided setup uses, as video files. Copy them to a USB stick or a media server and play them on the TV, then follow your brand guide for what to look for.

Play these files directly, not copies uploaded to YouTube or a cloud service: re-compression changes the exact levels the patterns depend on. Each file is about five minutes long, so loop it if your player allows.

About the files

SDR: 1920×1080, H.264, 30 fps, limited range, tagged BT.709. The sharpness pattern also comes in native 3840×2160 (HEVC), so a 4K TV doesn’t add its own upscaling to it.

HDR10: 1920×1080, HEVC Main10, PQ and BT.2020, with HDR10 metadata (mastering display P3-D65, 1000 nits; MaxCLL 1000, MaxFALL 400). Greyscale only.

Levels are written directly as video code values, so the below-black box survives instead of being clipped. The generators are in the project’s tools folder.

There are no Dolby Vision patterns: Dolby Vision fits itself to the TV, and making Dolby Vision test videos needs Dolby’s licensed encoder.
